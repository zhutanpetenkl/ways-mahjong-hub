# ways-mahjong-hub

## 项目简介

ways-mahjong-hub 是一个主要用于归档和发布多个独立 HTML 页面的仓库。  
仓库本身不针对任何特定域名或网站，旨在以结构化的方式保存和分享各类前端页面资源。

## 目录说明

```
ways-mahjong-hub/
├── pages/          # 存放独立 HTML 页面
├── assets/         # 存放页面所需的静态资源（图片、样式、脚本等）
└── README.md       # 本文件
```

- **pages/**：每个子文件夹或独立文件代表一个功能页面，可直接在浏览器中打开运行。
- **assets/**：按页面或用途分类存放 CSS、JavaScript、图片等公共资源。

## 页面归档说明

本仓库的页面文件均为独立 HTML，不依赖外部服务器或后端服务。  
每个页面可单独使用，无需额外配置即可通过本地文件系统或静态托管服务访问。

页面内容涵盖多种常见前端场景，供参考、学习或二次开发使用。

## 维护说明

- 本仓库由维护者不定期更新，新增页面或修复已有页面。
- 欢迎提交 Issue 反馈页面问题或提出改进建议。
- 如需贡献代码，请 fork 本仓库后提交 Pull Request，并遵循以下约定：
  - 页面文件放在 `pages/` 对应分类下；
  - 资源文件放在 `assets/` 对应分类下；
  - 保持文件结构清晰，命名简洁。
